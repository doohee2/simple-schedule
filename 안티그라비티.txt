우리는 구글 캘린더 API를 연동하여 특정 카테고리('점심', '저녁', '휴가', '기타')의 일정을 관리하고 빈 날짜를 추천해 주는 모바일 PWA 웹앱을 개발할 거야. 
기술 스택은 Next.js (App Router), TypeScript, Tailwind CSS, NextAuth.js(또는 Google API Client)를 사용해 줘.

내가 미리 생성해 둔 UI 디자인을 @design 폴더 밑에 png 파일과 md 파일로 첨부할 테니, 프로젝트에 적용하고 아래의 마일스톤에 따라 실제 구글 캘린더 데이터가 연동되도록 비즈니스 로직을 구현해 줘.

---

### [Phase 1: 프로젝트 세팅 및 UI 이식]
1. Next.js 프로젝트를 초기화하고 PWA 동작을 위한 `next-pwa` (또는 `serwist`) 패키지 및 `manifest.json`, `apple-touch-icon`을 설정해 줘.
2. 내가 첨부한 UI 코드(React + Tailwind)를 기능별 컴포넌트(Header, MonthCalendar, BottomSheet 등)로 분리하여 `components` 폴더에 이식해 줘.

### [Phase 2: 구글 인증 및 API 연동 (NextAuth)]
1. NextAuth.js를 사용하여 Google OAuth 2.0 로그인을 구현해 줘. 
2. 캘린더 읽기/쓰기를 위해 `https://www.googleapis.com/auth/calendar.events` scope를 반드시 추가해야 해.
3. 사용자가 로그인하면 해당 세션의 Access Token을 활용하여 구글 캘린더 API와 통신하는 커스텀 Hook 또는 API Route(`/api/calendar`)를 구성해 줘.
4. 달력 렌더링 속도 최적화를 위해 React Query(또는 SWR)를 사용하여 이번 달과 다음 달의 데이터를 캐싱(Caching)해 줘.

### [Phase 3: 상태별 캘린더 로직 구현 (데이터 바인딩)]
이식된 UI를 기반으로, 상단 카테고리 선택 상태(`selectedCategory`)에 따라 달력의 렌더링 로직을 분기해 줘.

- **[상태 A: 카테고리 미선택 - 전체 조회 모드]**
  - 구글 API에서 가져온 이벤트 리스트를 달력 셀에 매핑해 줘.
  - 제목에 ['점심', '저녁', '휴가', '기타']가 포함된 일정은 UI 디자인 코드에 지정된 색상으로 표시하고, 그 외의 일정은 하단에 "..."으로 렌더링되게 해줘.
  - 특정 날짜를 탭하면 [일정 조회 바텀 시트]를 열고, 해당 날짜의 전체 일정을 시간순으로 나열해 줘.

- **[상태 B: 카테고리 선택 - 약속 추천 모드]**
  - 주말(토, 일) 및 공휴일 데이터는 비활성화(Dim) 처리해 줘.
  - 선택된 카테고리(예: '점심') 키워드가 제목에 포함된 이벤트가 이미 존재하는 평일도 비활성화 처리해 줘.
  - **선택된 카테고리 일정이 없는 평일**만 필터링하여 '약속 가능한 날짜'로 UI를 활성화(Active) 상태로 렌더링해 줘.

### [Phase 4: 약속 추가 기능 (POST Request)]
1. '약속 가능한 날짜'를 탭했을 때 열리는 **[약속 추가 바텀 시트]**의 상태를 관리해 줘.
2. 바텀 시트의 Input(제목)과 Time Picker(시간)에서 받은 데이터를 조합하여 구글 캘린더 이벤트 추가 규격(JSON)에 맞게 구성해 줘.
3. [일정 추가] 버튼 클릭 시 Google Calendar Insert API를 호출하여 실제 캘린더에 반영하고, 성공 시 React Query 캐시를 무효화(invalidate)하여 달력 UI가 즉각 갱신되도록(Optimistic Update 고려) 처리해 줘.

[지시 사항]
첨부된 UI 코드를 분석하는 것부터 시작해 줘. 구조 파악이 끝나면 위 Phase별로 개발 마일스톤을 제시하고, 1단계부터 코딩을 시작한 후 로컬 브라우저 렌더링 결과를 보고해 줘.
